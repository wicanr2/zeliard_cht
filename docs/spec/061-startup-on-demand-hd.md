# 啟動進度與按需載入HD

狀態：READY，2026-10-22，限啟動視窗與大量補圖按需載入。使用者反映Windows開啟後長時間沒有畫面，Linux也可能相同，要求啟動視窗及用到時才載入HD。未確認重開機是必要條件，不先將原因歸為平台缺陷。

已證實的程式事實：`cmd/zeliard-preview/main.go`在`ebiten.RunGame`之前同步讀取字型、原版、全部HD與中文層。`loadCompleteArtwork`、`NewManualArtwork`及`CaveObjects.LoadManual`逐圖讀檔、核SHA、解碼並展開像素。正式HD包有18,280檔；冷啟動必須完成這些工作後才顯示視窗。

目標是先顯示有回應的進度視窗與錯誤，再初始化必要資料；未使用HD圖面延至實際匹配才核SHA、解碼及快取。不能先用未知或未核圖取代原版。Windows及Linux沿同一前端，Windows錯誤須可見且有日誌。研究、候選與量測沿`workplace/runtime-controls-v1/`，不得沿舊1.0.3收據宣稱新啟動已驗。

啟動包裝器先進入Ebiten事件迴圈，再於工作執行緒初始化CPU資料及載入字型／翻譯／資源索引。視窗持續顯示階段、耗時及可見錯誤；Ebiten材質與播放後端在主執行緒接入。背景初始化期間不執行原版，完成後才交給正常Update／Draw。錯誤同時保存在使用者目錄的啟動日誌，不能只在Windows隱藏主控台後退出。

新增顯式lazy建構入口，舊eager入口及其原子載入契約保留供既有證據重現。人工圖格、完整補圖、主角／刀光元件、敵人模板及後續城鎮，先核清單結構、資源鍵與來源，圖片在首次真正匹配時核SHA／尺寸並解碼。單張失敗保存失敗狀態，不反覆讀檔，整張保持原貌；不使用半張像素。快取按實際使用增長，不新增未授權素材或改封包格式。

基礎圖組另由[場景載入器](../../cmd/zeliard-preview/hd_loading.go)分成城鎮／城堡、人物／室內、洞窟基本圖組及其餘十個地形家族。HD開啟且首次進入該類場景才讀取。載入期間持續畫等待頁，釋放遊戲輸入、暫停原版與音訊並重設追趕時鐘；完成後在主執行緒安裝原版觀察掛鉤，再恢復操作。這些條件只決定何時讀檔，實際呈現仍核原有來源守衛。少量過場與完整魔王索引仍於啟動準備，不稱全部資產零預載。

驗證以缺檔／壞圖／第一次使用／重複使用、eager及lazy相同來源輸出、啟動頁面可畫且不推進原版為主。實際封包短啟動只記視窗與資產時間，不作HD 30fps或通關驗收。取消啟動時停止有界擁有程序，不留下背景載入工作。

實作入口：[啟動視窗](../../cmd/zeliard-preview/startup.go)、[延後核圖與快取](../../internal/prototype/hd/deferred_image.go)、[讀取／錯誤快取核對](../../internal/prototype/hd/deferred_image_test.go)及[限定視窗檢查](../../tools/runtime_controls_smoke.py)。新介面字模由既有[圓體工具](../../tools/prepare_rounded_font.py)的`--output`另存，保留舊交付字型。

交付沿051既有雙版本三平台流程，修正版為`v.1.0.4-20261022`，工作區`workplace/release-v104/`，完整包只放同版`dist-all`的`full-local/`。前版1.0.3不覆寫。新版採本工作區的新字模，封包及候選的驗證分開記錄，不重錄推廣片或重新通關。

限定核對已完成：1.0.4兩版Linux原生與兩版Wine輔助啟動、正式HD工具列；初始化時15812張圖面只註冊而未解碼。候選正常路徑的城鎮及第一洞窟按需載入通過。Windows／macOS真機、後段與室內各圖組仍未逐場景驗收。原始收據與平台身份見CONTEXT及同版smoke，不以候選GUI替代正式包實錄。
