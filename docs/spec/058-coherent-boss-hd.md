# 五組首領的完整構圖HD

狀態：CONFORMED，限定五張完整代表姿態、衍生元件及同圖README接入。完整首領動畫仍待人工驗證。只更換顯示素材及接入，不改原版動畫、座標、規則或存檔。

## 已確認問題與來源

使用者逐圖指出章魚、飛鳥、魔像、獨眼魔與披風魔王的HD有接縫或造型偏離。056已把來源圖格重組，但舊美術逐個16×16元件生成，連成整體後仍有矩形邊緣。魔像原版是藍白色塊，舊生成圖變成紅色肉塊。這是美術缺陷，不能以原生圖格吻合宣稱美術完成。

輸入為固定ZELRES3.SAR，SHA-256 `9c19b9c317d3006e11f8a5cad8ea1f226f8043e11c6467fa27f10eef33175ef0`；原生16×16圖格來自registered/manual-art.json，整體姿態及逐象限來源沿docs/images/creatures-layout.json及creatures-provenance.json。此處只有原生模板與靜態布局已證實，不新增首領正常出場或完整動畫的驗收聲明。

## 素材契約

- 先依原版完整姿態製作連貫圖，再裁切元件。沿既定手繪奇幻風格，保留原輪廓、姿態及配色。
- 章魚維持紅身、兩眼與連續觸手；飛鳥維持長頸、紅綠雙翼及長尾；魔像維持抽象藍白方塊，不加臉或肢體；獨眼魔保留粉紅身體、綠角、單眼及下方口腔；披風魔王保留細長身形、左向、藍綠身體、金飾及整片紅披風。
- 生成器使用內建imagegen，原圖、請求、引用及SHA留在workplace/hd-boss-coherent-v1。保留舊版，圖面只做裁切、目標尺寸取樣、原生透明遮罩及原版下層合成。
- 每個原生8×8圖格從完整圖切出HD，不再獨立生成。模板中未被完整圖涵蓋的象限保留原版，不引用舊錯誤造型。這些未涵蓋部分明列數量，不宣稱全動畫已重繪。
- 完整姿態以原生非透明像素及RGB逐項匹配，三倍HD整體覆繪優先於舊元件。使用當次選出的完整呈現來源，避免與上一畫格混用。失配或損壞安全退回既有來源；新素材不改判定或動畫計時。
- README採用同一份已接入的完整圖，不能只替宣傳圖片換圖。

## 完成條件

五張整體圖及原版並排目視，不能出現分格接縫或錯誤造型；素材登錄可重建，雜湊與透明範圍正確。完整姿態的來源匹配、遮擋拒絕、位置與畫布外不寫入做窄範圍檢查；實際首領全動畫仍交人工驗證。若發布新程式，使用新修訂版，不覆寫既有正式版。

五張已依原版完整構圖重繪並目視，魔像保留藍白抽象色塊，獨眼魔及披風不再呈分格貼片。430個原生16×16模板已改由整體圖切出；930個未涵蓋的非空象限維持原版，不回用舊錯誤造型。完整姿態優先覆繪已接入正式前端，來源與失配拒絕、原生透明邊界及區外不寫入通過；README使用同份coherent-bosses.json的五張圖。六個v.1.0.2封包逐檔核對通過，未新增後段正常出場或完整戰鬥動畫的通過聲明。
