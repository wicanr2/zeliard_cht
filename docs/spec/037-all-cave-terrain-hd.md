- 第一洞窟正常來源為`workplace/prose-v1/progression-v1/dungeon-entry.memory`及同名palette，正常按鍵及原始存檔身份保存在該目錄receipt。MPP1的header應與11B1:8000相同，全部25圖格與11B1:8030相同；核對後才列為已證實。其餘十組在正常載入前只稱結構候選。
- 擷取輸出集中`workplace/full-hd-v1/cave-terrain-sources-v1/`，含逐格原圖、分組總覽及來源／工具／地址空間／SHA收據。原版與完整衍生圖均留本機，不入Git。

- 新來源鍵使用01B1:C000..C013的19bytes，以及11B1:8000的48-byte header與8030起實際圖格數乘48的完整雜湊。C013..C016不供覆繪解碼消費，不當來源身份。不要把新增來源的未用區域與舊64-byte前綴混用。
- 舊兩個已驗64-byte前綴沿原契約接受；其他前綴必須同時匹配已知地圖、對應圖集、完整程式守衛及色盤。未知、越界、不同圖集或任一使用區byte失配均拒絕。只讀Go slice，不呼叫VM、不寫記憶體、亂數、輸入或存檔。

- 主角來源與完成來源、目前來源與保留完成快照都須在可辨識時屬同一地圖。切換至另一個已知地圖即撤除舊快照，不能只比較MPP家族相同。診斷顯示地圖及圖集身份，不能把它標成HD匹配。
