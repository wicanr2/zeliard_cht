單張試樣為1024×1536，SHA-256為`ea49f2489f990bd774fe98f1430fc2786b28b2bc22e7e2f2142b0b4ca8303ef0`。完整提示詞、參考來源及判讀為`player-prompt-v2.txt`、`player-generation-record-v2.json`與`player-art-review-v2.json`。以原版姿態與中文手冊右半外封面的盔甲輪廓為參考，不沿用左半其他遊戲廣告。生成alpha保持不變，只留本機研究區。

1. 先驗規格008的程式碼與色盤、規格007完整前景來源及當次14336原生像素／RGB。未知場景、來源、姿態或短畫格都整層退回，不寫畫布。
2. 從已驗地形底圖依原版順序合成居民，另記居民不透明遮罩。驗主角原圖後，依原版主角不透明遮罩還原其下層。
3. 還原點若有居民，使用當次居民原版色號；其餘點以地形原版RGB合成既有高清前景的同一世界位置。不得將仍含主角的畫布當還原底圖。
4. 九圖均為1024×1536。各圖使用相同995×1493裁切尺寸，水平範圍12至1007，依alpha128腳底輪廓加兩來源像素決定垂直位置。固定裁切與圖面雜湊在`coherent-frame-v1/player-art-set-v1.json`，C2bit1-phase4共用C2bit0-phase4。原版兩方向細節有差異，不宣稱精確鏡像。
5. 裁切直接以16位元預乘RGBA面積平均到48×72，不經原生16×24。目標像素`(x,y)`取來源整數矩形，邊界為`crop.Min + floor((x,y)×crop.Size/(48,72))`與下一像素的對應邊界。每色通道累加Go的`Color.RGBA()`值，除以矩形像素數再右移8位。圖外像素為透明零，仍計入分母。原圖及alpha不改寫，平均後alpha參與覆繪。區外不寫入，完整快照、原貌與HD共用同一來源時間。
6. 舊單圖整幅、單圖裁切及九圖單點取樣試作保留為歷史。面積平均版為`town_player_v4.go.draft`，避免高解析度盔甲細節縮小後顆粒明顯；不改原版姿態、位置或動畫時間。
7. 缺圖、壞圖或圖面身份不符時保留原貌。切換主題不執行原版、不改存檔。對話與跨場沿既有來源撤除契約處理。
