# 全遊戲 HD 覆蓋

狀態：DRAFT。使用者已將目標擴充為「完成全遊戲HD」。本規格建立覆蓋與驗收範圍，不授權尚未查證的圖像格式或繪製掛鉤進入正式路徑。

## 已確認的方向

- 沿已選定的 B 手繪奇幻、3倍畫布及 dosgolem 原版執行架構。原貌獨立保留，可隨時切換。
- 擴充所有玩家可見美術，包含城鎮、室內、洞窟、人物與姿態、敵人與首領、武器裝備與效果、片頭／標題／結局及圖形介面。
- 不改地圖、碰撞、位置、規則、動畫節點、輸入、存檔或配樂；文字沿既有中文層。完整中文翻譯另計，不把文字缺譯當 HD 美術完成。
- 使用者先前接受代表性正常路徑抽測，不要求完整通關。素材覆蓋仍須完整盤點；每個新增資源家族與場景分支都須有可追溯原版來源及至少一條正常路徑抽樣，不能只靠直接進入測試狀態。
- 原版與衍生完整圖面留本機。維持私人儲存庫及既有文件預覽例外，公開方式不變。

## 完成條件

| 層次 | 必須具備的證據 |
|---|---|
| 全量盤點 | 三個SAR每筆邊界、雜湊與用途分類；圖像記錄需列實際解碼數量及所有消費端變體。程式／文字／地圖記錄分類與美術分開 |
| 美術來源 | 每個原圖鍵、尺寸、色盤／遮罩、動畫及所屬場景可回查。未知或尚未分類的可見項目阻擋完成 |
| HD 圖面 | 每個必要來源都有經目視核對的手繪圖面與雜湊；同一人物、素材家族的外觀及相鄰動畫維持連貫 |
| 原版接入 | 唯讀原版來源，直接合成到HD畫布。保留繪製順序、遮擋及轉場撤除；未知／損壞來源安全退回，但正常已知素材退回仍算覆蓋缺口 |
| 玩家路徑 | 各場景家族與主要分支的正常進出、連續動畫、切換原貌／HD及存讀後恢復；有限抽樣不冒稱每幀逐像素一致 |
| 交付 | 完成後重建三平台本機完整封包及更新README圖片；依既有版號與dist-all契約另定新版本，不覆寫舊產物 |

## 盤點入口

- [資源盤點工具](../../tools/hd_inventory.py) 在Docker內核對固定原版三個SAR，輸出本地 `workplace/full-hd-v1/sar-inventory.json`。目錄含40、58及96筆，共194筆。此分母是容器記錄數，尚不是美術素材數。
- [IDA來源匯出](../../tools/ida_hd_resources.py) 對既有固定常駐程式的唯讀段傾印新建一次性資料庫，保留原始位址、bytes、函式名與未知等級。只用來定位圖像解碼及來源，未證實指令不當作實作規則。
- [全量覆蓋清單](../hd-coverage.json) 是目前唯一的資源記錄台帳，列194筆原始定位與雜湊、174筆名稱候選、84筆已核解壓結果。記錄數不能當作HD完成百分比。
- [離線解壓工具](../../tools/hd_decode.py) 與 [原版常式對照](../../tools/hd_decoder_oracle.go) 已對固定84筆零前綴候選逐byte比對，正式證據為 `decoded-v2/` 及 `decoder-oracle-v4/receipt.json`。涉及類型0、1、5、6、7；其餘分派只作指令定位，沒有本輪真實資料驗收。
- [居民來源工具](../../tools/hd_town_npc_sources.py) 沿既有007規格的來源／遮罩擷取五類、40姿態，其中34種RGBA圖面。來源在 `town-npc-source-v2/`，五張八姿態手繪圖及完整內建imagegen提示詞在 `town-npc-art/`。Muralla候選版共同合成已沿 [規格035](035-town-residents-hd.md) 限定驗收，不外推全城鎮。
- [居民註冊工具](../../tools/hd_register_npcs.py) 產生 `town-npc-registration-v1/manifest.json` 與40張48×72候選預覽。依原版alpha外框校準落腳點；來源相同時共用候選。正式合成用原圖面積取樣，預覽不當像素對照。
- 目前已接入範圍與舊收據仍以 [驗證矩陣](../../VERIFICATION-MATRIX.md) 為準。首次新增的完整覆蓋清單以本規格為入口，不能以README16類抽樣當成全量清單。

最新四家族增量見037的MPP8／MPP9／MPPA／MPPB接入契約與`workplace/full-hd-v1/cave-final-families-audit-v1.json`。新增106槽、102可見圖格、四個原版空白槽與九份結構地圖已驗；十家族共存及正常MPP1首戰／回城回歸通過。正常新增家族到達、捲動與事件仍未知，MPP1尚未全量對應的圖格及其他玩家可見美術仍有缺口，不稱全洞窟完成。

## 下一閘門

先證實圖像記錄解碼與實際載入位置，再建立資源鍵及場景對應。每個家族依原版證據、READY增量、實作與正常路徑抽樣依序推進，不移除既有守衛來假造全覆蓋。

RLE解壓已完成限定逐byte驗證。前輪直接把解壓結果當六位元圖格的 `sixbit-candidates.jpg` 未成立，保留原身份；本輪證實三平面變換之前仍需依資源類型處理色與遮罩，不能省略。

[三平面研究工具](../../tools/hd_planar.py) 與 [原版常式對照](../../tools/hd_planar_oracle.go) 對80筆補零研究buffer通過逐byte核對，收據為 `planar-oracle-v2/receipt.json`。這只證明變換，不代表80筆完整GRP形狀已解。[GRP來源工具](../../tools/hd_grp_sources.py) 的 `grp-sources-v3/receipt.json` 另證實MMAN152、TMAN46、CPAT157及MPAT242圖格，共597個／28656bytes，以及2256個有效遮罩bytes與正常原版RAM相同。CMAN164與DPAT191仍為結構候選，不升正常來源等級；NPC尾端資料用途仍未知。

城堡前景與原版四旗幟動畫已接入候選版，限定CONFORMED範圍見 [036](036-castle-hd.md)，未更新既有封包。居民限定增量見035；對話背景、其他城鎮、洞窟與全量人物仍有缺口。不得因解壓或圖格來源一致就跳過正式HD繪製與正常路徑驗證。

全洞窟地形入口為 [037](037-all-cave-terrain-hd.md)：11組MPP共378原圖，31份地圖306048格與原版解壓常式相同；31地圖／11圖集來源已接入。MPP2、MPP3、MPP5、MPP6、MPP7、冰窟分別34／43／52／36／61／21槽接入可選前端。MPP7含58個可見圖格、三個原版全零槽，四圖1161216像素、LLAMA字帶及十一個尾端白熱圖樣差異通過；MPP6四圖及其餘各三圖回歸通過。六家族同時載入後正常MPP1首戰／回城35點與實際視窗回歸通過。正常新增家族進出、捲動、事件與切回未驗，其餘家族、敵人及首領仍未完成，不升格為全洞窟完成。
