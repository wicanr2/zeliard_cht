# 系統介面字級

狀態：限定CONFORMED，2026-10-22。先完成READY契約再實作。使用者指出作弊頁文字太小，要求系統設定文字可調且更大。這是已授權的可逆介面設定，不涉及原版規則、遊戲內對話或存檔格式。

## 現有來源與範圍

已證實：`cmd/zeliard-preview/main.go` 的 `game.text` 呼叫固定16像素的 `bitmap.Font.Draw`；工具列與設定頁共用。`internal/prototype/bitmap/font.go` 的圓體灰階遮罩已具16、18、24、32像素，沿用粉圓2.1，不另換字型。這些都是前端程式證據，無須逆向DOS程式。

工具列新增「字級」，設定頁提供16、24、32像素。新設定及缺少欄位的舊設定預設24像素，無效值回到24。選擇即時套用，以相容可選欄位 `ui_text_size` 存入既有 `controller.json`；不改Version及原版USR。選擇16可還原原有大小。

設定本文直接以選定解析度畫字，不把16像素圖放大。說明依可用寬度換行，三檔均需完整呈現。動態裝置名稱或鍵名過長時可顯示省略號；不以縮小字級補救。工具列與底部狀態區最高24像素，避免擴大畫布或遮住遊戲；鍵盤入口縮短為「鍵盤」，手把入口縮短為「手把」。其餘設定標題保持完整名稱。

字級頁沿既有面板暫停、輸入釋放與返回閘門，方向鍵／Enter、滑鼠及已綁定手把皆可操作。開關字級頁不改HD選取或CPU倍率。工具列原貌、HD、速度、手把、作弊及暫停原位置保留，鍵盤區右側分出字級按鈕。舊錄影保留既有介面身份。

## 垂直鏈與核對

`controller.json` → 相容讀取及合法字級 → 工具列／字級頁 → 共用文字排版 → 系統各頁 → 原子保存 → 冷重開恢復。原版畫面、遊戲內中文和HD合成不受影響。

驗證限設定相容讀寫、固定字級與裁切／換行、編譯，以及實際視窗字級選擇、作弊／速度／鍵盤／手把頁、冷重開及原版steps／cycles不前進。不要重新開啟全遊戲、幀率或通關驗收。三平台正式包與影片本次不覆寫；先提供本機候選。

工作區：`workplace/ui-text-v1/`。實作入口：[系統字級](../../cmd/zeliard-preview/ui_text.go)、[字體排版](../../internal/prototype/bitmap/text.go)、[設定](../../internal/prototype/controls/controls.go)。驗證入口：[限定視窗檢查](../../tools/ui_text_smoke.py)。

## 本機候選與結果

啟動使用 `bash tools/play-readable.sh`，從工具列右側選「字級」。候選為`development-ui-text-v1`，沿正式1.0.4程式加上本規格，借用既有本機圖庫。重建使用 `bash tools/build-readable.sh`，需要目前工作區的`build.work`、既有CPU候選素材、1.0.4獨立dosgolem來源及Go快取；這是本機候選入口，不是可攜正式封包。建置、字型製作與驗證均在Docker，原版／借用素材唯讀。

`controls-bitmap-tests.jsonl`保存設定／字體套件測試，涵蓋舊設定缺欄位、非法值回復、三檔保存及冷讀、其他設定保留、全半形換行、裁切回報，以及32像素直接灰階遮罩。`smoke/receipt.json`為實際視窗限定結果：預設24、滑鼠與鍵盤切換、32像素四種設定頁與鍵盤綁定等待、冷重開32、作弊維持預設關閉，原版steps／cycles皆0，遊戲存檔bytes及mtime不變。不是正式六包、通關或幀率驗證。
