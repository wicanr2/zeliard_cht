## 已審查的架構契約

1. 原版 EXE、資料、規則與記憶體保持原樣，由 dosgolem 執行。所有寫入另落在 scratch。
2. 合成順序為原版畫格 → HD 圖面 → 中文疊字 → 前端工具列。原貌能獨立擷取；未辨識素材保留原圖。

4. Zeliard 專屬適配留本專案。共用 dosgolem 只讀；目前使用逐檔固定的本地來源快照。
5. 手把先映射到前端動作，再經原版鍵盤掃描碼送入。此映射不宣稱原版 gameport 硬體相容。
6. 按下／放開事件同一執行緒送入。鍵盤、手把同時按同一鍵時，任一來源仍按住就不放開。
7. 工具列或綁定捕捉輸入時，遊戲暫停推進並釋放已按住動作；原版 Esc 在遊戲畫面仍送入原版。

狀態為CONFORMED，限當次來源閘門與四個新增正常場景的可撤回顯示擴充。`workplace/scene-v1/consumer-evidence-v2.json`以兩條正常原版路徑補21個完成header；10個抽樣點的色號、色盤、64KiB段與完整收據不變。國王、武器店、小屋、Marid長老均實際走22CD／2344，字型、程式碼、完整來源及模組前綴相符。完整配對13點及舊HUD／使用96點回歸通過；四種名稱正常GUI由v1已達三種與v2正常F7補Marid合併，v1導航失敗仍保留。40個未走過來源不在正常驗收範圍。

- 既有九來源維持原始定位。另由已驗2345字形契約與固定SAR導出44個場景候選的完整bitmap，保存於同研究區 `source-contract.json`及 [HUD索引](../hud-source-index.json)。其中未走過的來源仍標強推論，不稱全遊戲已驗。銀行與道具店標題沿既有層處理，ENEMY不在本契約。
- 新來源不預設載入基址。在實際01B1:22CD入口，以SI減去來源檔案內相對header導出基址；範圍、完整header／原文及64-byte模組前綴均須相符，且只能匹配一個來源。這是當次執行的顯示證據，不以候選字面直接觸發。
- 入口另驗F504字型指標為F856、768-byte字型SHA-256為 `f16d564fee5c4472914b4dc64cf467bcd05da89125288a83b0b065d164707d07`及既有22BF至2386程式碼雜湊。2344完成時SI、完整字形與色盤也須符合。缺少任何條件時保留原貌，不新增遊戲分支、存檔或輸入。
- 新增來源沿用UTF-8兩欄TSV，所有53列須完整、唯一、可顯示且含陰影仍落在既有安全區。名稱保留原文專名，新增中文為待校訂試譯；不決定正式翻譯格式或版面。
