## 已審查的架構契約

1. 原版 EXE、資料、規則與記憶體保持原樣，由 dosgolem 執行。所有寫入另落在 scratch。
2. 合成順序為原版畫格 → HD 圖面 → 中文疊字 → 前端工具列。原貌能獨立擷取；未辨識素材保留原圖。

4. Zeliard 專屬適配留本專案。共用 dosgolem 只讀；目前使用逐檔固定的本地來源快照。
5. 手把先映射到前端動作，再經原版鍵盤掃描碼送入。此映射不宣稱原版 gameport 硬體相容。
6. 按下／放開事件同一執行緒送入。鍵盤、手把同時按同一鍵時，任一來源仍按住就不放開。
7. 工具列或綁定捕捉輸入時，遊戲暫停推進並釋放已按住動作；原版 Esc 在遊戲畫面仍送入原版。

- `37CCh` 把 `3CAFh` 起九列搬到 VGA，完成事件為 `3804h`。名稱位於 X=BH×4、Y=BL+1。正常兩筆 SI=AD1Dh／AD2Ch，BX=1871h／187Bh，對應 X=96、Y=114／124。
- 來源模組、完整名稱、函式簽章及暫存名稱像素全部相符後才準備覆繪。只在完整搬移後擷取 VGA 名稱前綴；價格區不覆繪。原版畫面或色盤改變時移除。
- 固定 [正常交易鍵序](../../tools/weapon-shop.commands) 由冷新局領賞，選第一件武器、確認交易、告別並查看裝備。比較完整 1 MiB 記憶體、色號、色盤、CS:IP、steps、cycles 及文字區域。報價及裝備顯示依下列各節接入，交易價格不改寫。

## 武器報價與資金不足 prototype

仍為 DRAFT，使用既有 `-dialogue-text` 與 `-labels-text`。來源見 [武器店索引](../weapon-source-index.json)，實作為 [quotation.go](../../internal/prototype/overlay/quotation.go)。未同時載入商品來源時保留原版報價。

- 報價依正常來源順序組合：B0DDh 前綴 → 商品 ASCIIZ → B0E7h → B106h → BC33h 售價 → B115h → B046h → BC33h 折抵 → B056h → B0EDh 確認句。固定 SAR2、模組前綴、完整片段 bytes、來源指標與 MCGA 字形參數須相符。未知來源或順序立即退回原貌。
- 商品譯名共用 `Labels` 的已驗來源，不另複製翻譯。四個中文模板保存在對話 TSV，分別須有一次 `{item}`、`{price}`、`{trade}` 及無代入欄位的確認句。漏項、重複、未知代入欄位與缺字時拒絕載入。
- BC33h 為重用暫存區，數字以單一 FF 結束，後一個 byte 不屬結尾契約。分別在原版字形完成後保存售價與折抵的字串及八列色號圖形；來源限1至8位十進位數字，不計算價格，不從格式化後的最新暫存值倒推前一筆。
- 中文直接排在既有三倍安全文字區，最多三行，數字整組換行。保存的原版數字圖形以三倍最近鄰合成，保留墨跡與黑底；位置隨中文排版移動。商品、售價、折抵與確認句各等原版相應片段完成才顯示，未完成片段暫留白。這是顯示試作，未定正式出字節奏。
- 範圍外未知像素、未知畫框與過期歷史仍退回；畫框遮擋沿「彈窗遮擋」節契約。新中文不得寫入是／否框。數字圖形與目前色盤逐像素核對，完整原版狀態仍需相同。
- 第二件武器的正常資金不足分支不顯示報價確認框。AF54h..AFAFh 對應 SAR 檔案 `0x1876B..0x187C6`，沿既有逐字、捲動及待續標記覆繪。驗證入口為 [不足鍵序](../../tools/weapon-insufficient.commands)，必須翻頁、告別並回城鎮，金幣仍1000。

正常第一筆報價／購買9點與資金不足11點完整原版狀態均已驗。其他商品、無舊武器、盾牌、出售與所有價格範圍尚未驗，不把此切片稱為所有商店報價完成。

## 裝備頁標題與物品名稱 prototype

仍為 DRAFT，來源見 [裝備頁位址索引](../inventory-source-index.json)，實作為 [inventory.go](../../internal/prototype/overlay/inventory.go)。固定SAR2 payload `0x401E`、3613 bytes載入 `01B1:A000`，與武器店模組分開核對前綴及完整來源。

- 四個分類標題及「無」走 `AA2Bh` ASCIIZ迴圈，`AA30h`為NUL完成事件。來源指標、每字X增加8、Y、AH顏色、固定程式bytes及色號表須相符；不以單一SI或文字字面辨認畫面。
- AH=1為白字色號9，AH=2為紅字18，AH=3為綠字27。彩色標題先以AH=5、色號45在右下各一原生像素畫陰影。覆繪保留目前原版顏色，在三倍畫布畫24像素中文字及3像素陰影，限定原文字寬度與9原生列內。
- 練習劍名稱由兩段ASCIIZ來源組成，分別為檔案 `0x4D03`的Training及 `0x4D0C`的空格與Sword，走既有五像素小字入口。兩行試譯為「練習」及「劍」，仍待正式術語與版面校訂。
- 七個新增文字鍵存入既有UTF-8選單TSV。只有已確認的大字來源採八像素步距，其餘來源不變。缺字、超寬、未知色號、來源／畫面／色盤失配時保留原貌。
- 原版畫框遮住的舊選單可保留內部記錄，必須逐一驗證沒有可見像素。開啟、放開、Return關閉及Return重開均用 [正常鍵序](../../tools/inventory.commands) 驗證，完整原版記憶體與輸入不改動。
- 實際視窗以X11送按下／放開，診斷觀測確認原版已收到事件。按住期間依原版指令步數控制，Return使用既有鍵序的500k預算，放開後依序前進1m／2m／1m再核對開啟／關閉／重開畫面；此值只屬已驗鍵序，不宣稱最低按鍵時間。可用自己正常產生並核對雜湊的存檔冷F7載入，不以原包存檔或記憶體注入取代玩家路徑。

配對涵蓋購得練習劍後的裝備頁；實際視窗另由自己新建存檔冷F7讀回，驗相同初始武器的開啟、關閉及重開，沒有新交易。其他物品、可用道具、魔法與裝備切換操作尚未驗，不稱整個裝備系統完成。
