5. 手把先映射到前端動作，再經原版鍵盤掃描碼送入。此映射不宣稱原版 gameport 硬體相容。
6. 按下／放開事件同一執行緒送入。鍵盤、手把同時按同一鍵時，任一來源仍按住就不放開。
7. 工具列或綁定捕捉輸入時，遊戲暫停推進並釋放已按住動作；原版 Esc 在遊戲畫面仍送入原版。

## 存讀檔與速度提示 prototype

來源及呼叫鏈見 [對話位址索引](../dialogue-source-index.json) 與 [研究紀錄](../../RESEARCH-LOG.md)。本節仍為 DRAFT，不改輸入、速度數值或原版存檔識別。

- 固定 SAR1 payload `0xCEB5` 對應 `01B1:6000`，只接入此已驗模組；SAR2 房屋模組對應 `01B1:A000`；固定 STICK.BIN 檔案起點對應 `01B1:0100`。每次均核對來源 SHA-256、模組前 64 bytes 及完整來源字串。
- 是／否沿用 ASCIIZ 路徑。名稱、退出、讀取及速度提示以 FF 結束，CR 換行；入口 `01B1:291A`，完成 `01B1:2939`。X 來自 BX，Y 來自 CL，原文字形寬八、高八原生像素。
- 中文直接在三倍畫布繪製，每行只能用該行原文字前綴的寬度。逐行核對及清除原字，不能用最長行寬涵蓋所有行。速度提示第二行後的數字、名稱輸入值及其餘資訊保留原版像素。
- 缺字、譯文超過對應原文行寬、超行、來源或畫格失配時不套用。原始輸入值、檔名及控制碼均不翻譯。
