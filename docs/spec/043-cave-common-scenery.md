正常來源為[城鎮路徑探針](../../tools/hd_town_path_probe.go)以固定包內SAVEM1冷F7讀回、正常入Malicia及使用魔法石的路徑。存檔前史未知，沒有記憶體注入或快照還原。完成點使用已核的01B1:7114，與手動觀察的繪製中快照分列。

[來源工具](../../tools/hd_cave_common_sources.py)核SAR3 record54的DCHR解壓buffer1872bytes，SHA-256 `ac077b64a652afebeb88b907dd61c2411ce2fbac138aec4663c09fb48c0af998`。沿已核三平面變換後，SHA-256 `7b4628728e0b6ce81a25b7bc0bbb3b4eedd640b0da102924b4384da0d38f690b`，39格與正常資源段11B1:8C00..934F逐byte相同。位址規則沿[011](011-cave-hd.md)的8030+(id-1)×48，對應ID64..102。載入常式及各圖格consumer仍須另核，不把字串候選當載入控制流。

## 接入閘門

1. 核共用圖集載入位置及平台／其他必要圖格的消費端，保留原始函式名、位址、bytes與證據等級。
2. 依真實相鄰圖格準備手繪圖，保存完整提示詞、引用及產物SHA、尺寸、透明與接縫；現有Muralla入口圖保留其來源契約。
3. READY後才擴充來源守衛，不能把所有64以上ID通用放行。缺圖、資源或位置失配須原子退回。
4. 以正常平台上下移動、跳上／離開及捲動取得原版／覆繪完整狀態配對，再驗實際視窗與原貌切回。其他共用圖格按用途抽樣，不以單張圖集稱全洞窟完成。

正式候選、封包及版本保持原身份；本規格尚未授權正式前端修改。

## 目前候選與正常操作

`cave-common-registration-v1/manifest.json`保存三個24×24圖格及72×24連續候選。圖面直接從1254×1254生成原圖的主體裁切取樣，再以本平台的原版非零包絡裁切，框外寫入零像素。包絡1287個HD像素中仍有51個全透明像素，須補圖或修正註冊，不把候選當完成。

正常v3已站到平台中央、升起並走到右側通道。v4重播首個升起點，RAM／暫存器／色號／色盤／steps／cycles與v3相同，再正常Down、Up，原版C004表第一項列值17→24→17，兩張升起原圖相同。這只是原版正常操作與來源證據，未接HD或GUI，不宣稱所有原版狀態的配對。
