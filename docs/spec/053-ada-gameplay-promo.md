# ada 遊玩實錄與新版推廣片

狀態：限定完成。使用者指定在 ada 錄製遊玩片段，再重新製作推廣影片。使用 v.0.4.1-20261021 完整 HD 包，不改遊戲程式、既有封包或已發布 tag。

## 錄製範圍

- 在 ada 的 Docker 容器內執行最新版，保留主機、工具映像、二進位與原始遊戲雜湊。先確認顯示與音訊工具；有硬體繪圖時記錄實際 renderer，不能只憑主機有GPU就聲稱使用GPU。
- 以正常冷F7及方向／攻擊／跳躍操作錄製城鎮、中文對話、第一洞窟、接敵及受擊HD。只送正常輸入，不注入狀態或改玩法速度。使用獨立的可寫存檔副本。
- 交付一段連續遊玩實錄，以及60秒推廣片。推廣片以新錄動態片段為主，加入短標題、中文對話、原貌／HD切換及工具列展示。遊戲畫面保留原色，不用舊片或靜態圖冒充新錄。
- 原版音樂與音效沿已核MSCAdLib／Nuked-OPL3路徑擷取，保存同步來源；若剪輯需連續配樂，使用已追溯的原版錄音，註明與現場聲的差別。

## 目錄與驗收

本機工作區為 `workplace/ada-promo-v1/`。正式影片放 `dist-all/v.0.4.1-20261021/promo/`，不覆寫v.0.4.0影片。只有取得實際ada錄影後才更新README影片入口及完成聲明。

驗收包含視訊／音訊長度、非靜音、音量、黑幀、凍結、中文字幕裁切及代表抽幀目視。記錄原始影片、音訊、輸入日誌、剪輯時間線與SHA-256。錄影用的X伺服器及音訊程序須有有界擁有程序與finally／trap；完成後清除本任務容器。

## 連線現況

本機Docker只有default context，起初ada別名無法解析。使用者提供既有登入腳本後，經主機既有SSH agent連線；登入腳本及憑證不入Git。遠端Docker socket要求sudo，採sudo -n控制Docker，所有錄影與分析仍在非root容器內執行，不改使用者群組或daemon權限。

ada為28核心、約64GB記憶體主機，GPU為NVIDIA RTX 2000 Ada Generation，driver595.91.07。沿既有kdzz-gpu-verify:20261021-r1，不另建重複映像。VirtualGL的EGL後端確認NVIDIA硬體繪圖，NVENC編碼通過；實際遊戲的映射函式庫也含libvglfaker及NVIDIA函式庫。Xvfb只提供隔離的二維顯示，不用軟體繪圖冒充GPU。

固定AppImage、錄影程式與導航來源經SHA核對後傳至專屬工作區。遊戲與原始輸入唯讀掛載，存檔及錄影另設可寫目錄，UID/GID為1000。第一份錄影在HD下使用原貌入口圖樣而停止；保留失敗身份，只修錄影導航，於同一工具鏈重錄通過。新錄影完成正常城鎮、教堂中文、原貌／HD切換、第一洞窟攻擊及跳躍、鍵盤與手把選單，正常DOS退出0，存檔內容及mtime不變。

## 成品與驗收

- [錄影工具](../../tools/record_ada_promo.py)保存原始60fps NVENC影片、PulseAudio監聽PCM、原版生成WAV、10張實際視窗與輸入日誌。原始影片SHA與AppImage二進位核對後才剪輯，不使用前版遊玩片段。
- [剪輯工具](../../tools/make_ada_promo.py)交付55.45秒連續遊玩片段，保留原次序及正常對話／換場／暫停，沒有加速或循環。960×680、60fps、AAC雙聲道，同期聲mean -21.5dB、peak -3.6dB。音訊以同主機X11原始epoch與parec啟動epoch對齊，保留程序啟動的小幅時間誤差，不宣稱逐取樣同步。
- 推廣片60秒、1280×720、H.264／AAC雙聲道。32秒取自新錄遊玩影片，其餘為同次錄影的中文對話、比較圖、設定與短字卡。配樂沿既有原版標題曲，不把它標成同期聲。畫面只裁切及加框，遊玩不調色；標題卡另加深底圖。深綠／銅金、動態主線與短開場取代前版安排。
- [訊號檢查](../../tools/verify_promo.py)核兩片串流、時長、非靜音及黑幀。推廣片mean -18.6dB、peak -4.5dB，沒有長黑幀、兩秒以上靜音或未分類凍結；六格抽幀與57秒結尾卡已目視，字幕無裁切。連續遊玩片保留原版停頓，不冒稱全程無靜音。
- 正式檔為同版promo內的`Zeliard-v.0.4.1-20261021-ada-gameplay.mp4`與`Zeliard-v.0.4.1-20261021-promo.mp4`。`provenance.json`、`quality.json`、`gameplay-quality.json`與主manifest保存來源及SHA。未上傳含原版素材的影片，不移動已發布tag。

本機清除傳輸tar等重複副本251,035,648配置bytes，ada清除重複AppImage及解包層480,342,016配置bytes。兩端正式影片、原始錄影／音訊、截圖、來源、日誌與失敗身份保留。專案容器均已移除，root-owned檔案及誤建.md目錄均零，詳工作區的兩份cleanup與hygiene收據。
