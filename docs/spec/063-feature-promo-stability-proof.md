## 證明與停止線

連續錄影搭配同時間的前端觀察資料，逐筆記錄HD開關、完成來源使用、地形／背景匹配、對話／平台狀態及作弊設定。樣本以實際更新去重，不把輪詢重讀當成不同畫格。影片另抽樣及檢查原貌參考與HD區域的顏色差異，避免只看開關就宣稱HD真的存在。

影片核對補證：原貌PNG仍完全使用固定原生色，但YUV420影片解碼後的彩色色差不能保留此判準，原貌對照被誤判為HD，故色盤距離法不可用。本輪以原版最近鄰3倍畫面的亮度格線作校準：同一3×3格內梯度對跨格邊界梯度的比值，原貌參考約0.028，HD參考約0.394。兩組已知同狀態參考分離後，以其區間中點作門檻；證明片的每個解碼畫格均須在HD側，並保留前端來源核對。居民只取文字框外畫帶，洞窟取遊戲viewport，不用工具列或中文字形充當HD證據。這是本場景的輔助像素證明，不當通用HD偵測器。影片內容與切點不因檢查方法改變。

正常原版等待、站立與對話提示允許畫面靜止，必須與剪輯製作的靜態字卡分開標示。黑幀、非靜音、時長、字幕邊界與所有來源版本照既有影片流水線核對。若指定區間出現原貌回退，保留失敗來源並查明，不能刪除異常畫格冒稱問題已解決。

本片只證明錄到的居民及平台範圍。未到達的精確站位與全遊戲每幀不外推；影片幀率不當成遊戲效能宣稱。使用者已接受目前幀率，30fps不再是本次交付閘門。

## 限定交付結果

正式60秒主片與兩段原尺寸證明完成。主片10–17秒對話210幀、17–30秒平台390幀，HD選取及高清亮度細節逐幀維持；完整對話10.9秒327幀、平台28.57秒857幀，對應161與248筆去重來源，無原貌回退。這些是實際編碼畫格，不當成不同遊戲畫格或30fps效能證據。
